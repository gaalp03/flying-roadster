# Credits

Flying Roadster is an original game. Code, 3D models (all generated procedurally in code), textures and UI were made for this project.
No sound in the game is synthesised: every sound effect and the music track is a downloaded recording released under
**Creative Commons Zero (CC0 1.0, public domain dedication)**, edited only by trimming, looping, level normalising and MP3 encoding
(`tools/build-audio.mjs`).
